Приложение для учета заказов в детском магазине - Kids Shop с использованием PostgreSQL

Использовано:
- Java 21
- PostgreSQL - база данных
- JDBC - подключение к БД
- Maven - управление зависимостями
- Flyway - миграции базы данных

Порядок запуска и работы:
1. запускаем приложение в Intellij IDEA
- подключаемся к БД,
- выполняем автоматический запуск миграций с использованием Flyway,
- создаем и заполняем таблицы данными,
- демонстрируем CRUD-операции с выводом результатов в консоль
- демонстрируем запросы sql из файла test-queries.sql
